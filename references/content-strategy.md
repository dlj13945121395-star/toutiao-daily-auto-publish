# content-strategy.md · 微头条内容战略与数据闭环

> 面向「策略层」：写什么、怎么勾住人、爆了怎么复盘、数据怎么回流。
> 操作细节见 `writing-spec.md`。

## 1. 赛道定位（换赛道改这里）

- 默认赛道：**AI（普通人用 AI 搞钱 / 提效 / 避坑）**（2026-09-01 由「人情世故 + 真实故事」改为 AI）。
- 选题来源：每日 WebSearch / 热点选题技能 抓当日 AI 相关热点（新模型 / 新工具 / 平台政策 / 普通人用 AI 的真实案例），挑「能落到普通人搞钱、提效、避坑」的热点 3 条。
- 人设：一个爱折腾 AI 工具的普通人，把亲测好用的玩法、踩过的坑、能落地的搞钱/提效思路，用大白话讲给普通人听。第一人称，允许不完美、允许翻车，比完美更真实。
- AI 工具真实经历（美图API/影刀RPA/OpenClaw 等）是核心素材，落点就是「这东西普通人怎么用、能省多少事/赚多少钱、有哪些坑别踩」，不空谈概念。

## 2. 字数规范

- 每篇 300–500 字（微头条最佳互动区间）。
- 短句长句交替，别每句一样长；允许偶尔跑题、犹豫，比完美更真实。

## 3. 钩子库（10 类，每日 3 篇类型不重复）

| 类型 | 公式 | 示例开头 |
|---|---|---|
| 反常识 | 常识是错的 + 为什么 | 「都说 AI 会取代程序员，但真相正好相反——」 |
| 亲历 | 我刚经历 + 细节 | 「今早我用 AI 干了件离谱的事：」 |
| 痛点 | 你有没有过 + 共鸣 | 「每次写周报都头疼的，举个手」 |
| 数字 | 具体数字 + 冲击 | 「一个动作，让我 7 天涨了 2000 粉」 |
| 预警 | 再不 X 就晚了 | 「这波红利，普通人只有 3 个月窗口」 |
| 圈层 | 打某个群体 | 「做自媒体的，这条能救你半条命」 |
| 悬念 | 留一个坑 | 「我没敢发出来的那部分，是……」 |
| 对比 | A vs B | 「同样用 AI，有人月入过万，有人啥也不是」 |
| 时间 | 时间点钩子 | 「凌晨三点，我发现了平台的潜规则」 |
| 捷径 | 给方法 | 「三步，把 AI 变成你的免费员工」 |

> 补充（2026-09-16 整合自起号课程截图）：课程另列 7 类高点击开头，可据选题取用，不重复即可——
> **利益式**（开头直接讲好处，抓逐利心理）、**身份式**（锁定特定人群拉近距离）、**场景式**（描绘具体生活场景让人代入）、**权威式**（借专业人士/官方信息背书）、**争议式**（抛有争议观点激发评论）、**提问式**（直击痛点发问带人往下读）、**金句式**（扎心/通透句开篇定基调）。

## 4. 爆款复盘框架（R1–R6，选题/写作时用）

- **R1 抢共振热点**：蹭 24h 内的共振热点，自然契合赛道，不生搬硬套。
- **R2 落普通人用处**：每个热点都落到「对普通人有什么用」，别只复述新闻。
- **R3 具象隐喻**：用生活化比喻把抽象技术讲懂（如「模型就像刚毕业的实习生」）。
- **R4 时间+亲历钩子**：开头带具体时间/亲历细节，增强真实感。
- **R5 资本锚**：点出背后资本/大厂动向，提升信息厚度。
- **R6 14 天 1 主稿**：每 14 天围绕一个主线深挖一篇，建立人设连贯性。

## 5. 数据闭环（R7–R10，发布后执行）

- **R7 每篇立场句**：结尾亮明你的立场，别中性总结（立场=被讨论的燃料）。
- **R8 结尾二选一**：结尾抛「你站哪边？A/B」式二选一，诱导评论。
- **R9 自己首评置顶**：发布后自己抢沙发第一条评论，补充观点/抛问题。
- **R10 3 天回访篇**：爆款后 3 天内发回访/延展篇，承接流量。

## 6. 数据诊断与处方

### 诊断指标
- **收藏/点赞比**：正常 0.2–0.6。>1.0 说明「内容被当资料收藏但没人讨论」。
- 平台推荐权重：**评论 > 转发 > 点赞 > 收藏**。

### 真实样本
- 阿里千问篇：14 赞 / 28 收藏 / 15h → **收藏/点赞 = 2.0**。
- 判读：内容价值达标（被收藏=以后要用），但社交传播断（没人评论转发）。
- 处方：补 R7 立场句 + R8 结尾二选一 + R9 首评置顶 + R10 回访篇。
- **《半年 981 万单 AI 副业，最赚的偏偏不是写文案》（2026-09-11 反馈：展现/阅读很好）**
- 判读：**数据型反常识 AI 副业** 是高潜方向。公式：权威数据（平台/报告）+ 反常识结论（最赚的不是大家以为的 X，而是 Y）+ 极端小人物案例（13 岁女孩三天赚一万八）+ 务实落点（工具不重要，跑通交付才重要）。
- 处方：将该模式升格为常备选题类型，见下「高潜选题模板」。
- **《我用WorkBuddy半小时做了个投标skill，一天挣了3300块》（用户 2026-09-14 提供，展现/阅读很高）**
- 判读：**第一人称亲历型**同为高潜方向，与「数据型反常识」并列。公式：堵质疑开头（先排除"卖课/卖工具"）+ 具体人物起因 + 可信细节堆叠 + 一个简单动作 + **承认第一版翻车** + 可复用方法论 + 具体金额结果 + 金句升华。
- 处方：已固化为「高潜选题模板 D」，**新号 / 冷启动期优先使用**（立人设、攒信任）。

### 黄金窗
- 发布后 **6h** 内决定 70–80% 流量。
- **过窗不改正文**（改正文会重新过审、掉推荐）；只做首评/回访篇救。

## 7. 反馈回流流程

1. 任意篇爆了 → 把 点赞/收藏/评论/时长 发给我（热点猎手）。
2. 我算 收藏/点赞比 → 对照上表诊断 → 拆 6 维爆火因子。
3. 写回本文件 → **2 篇以上印证**才把经验升格为 `writing-spec.md` 的硬规则。
4. 持续迭代钩子库与复盘框架。

## 8. 文章主结构（强制 · 用户 2026-09-14 指定）

> 这是文章与微头条的**主骨架**；下面的「高潜选题模板 A/D」降级为**素材手法**，不再单独成篇。

**角色设定**：你是一位擅长写**热点新闻见解文章**的作者，请根据**符合账号定位（AI 搞钱 / 提效 / 避坑）的热点事件**写文章。

**结构**：标题 + 热点概况 + 态度/观点 + 结尾

| 部分 | 占比 | 要写什么 |
|---|---|---|
| 标题 | — | 2-30 字，带钩子（具体数字 / 反常识 / 悬念） |
| **热点概况** | **≈25%** | 描述和说明热点事件：谁、什么时候、发生了什么，带具体数据或细节。用说明 + 叙述的句式 |
| **态度/观点** | **≈60%** | **主体、最重要**。表达自己的态度，**煽动情绪、激起共鸣**。第一人称与读者对话（「你有没有过…」「换我我也…」），落点压到读者处境（工作 / 收入 / 焦虑 / 机会） |
| **结尾** | **≈15%** | 对事件**总结升华主题** + **引导读者评论**（提问 / 二选一 / 征求意见） |

**表达要求**：口语化、用词简单易懂、逻辑清晰、过渡自然、使用「说明 + 叙述」的句式。

**为什么把 60% 压在观点上**：头条推荐权重 **评论 > 转发 > 点赞 > 收藏**。
观点段煽动情绪 → 激起共鸣 → 结尾问一句 → 评论区开炸。这是拿推荐量的核心杠杆。

**微头条（见下方范本 ②）**：钩子一句 → 引流句 → 4~5 个话题标签，总长 200~500 字符。
微头条**不写完整观点文**，职责是「钩住人 + 把人带回主页看长文」。
⚠️ **微头条品质规则（整合自起号课程 · 强制）**：黄金 3 秒法则——首屏前 3 行（约 50-80 字）直接决定打开率，钩子要单刀直入、带具体画面或反差；正文高频换行留白、每句 ≤25 字、口语化、去 AI 味（见 §8.2 替换表）；结尾引流句必须带互动引导，把人引回主页看长文。

> ⚠️ **话题标签硬规则（2026-09-14 用户指定 · 强制）**：话题不能再用写死的常青标签（如固定 `#AI工具 #人工智能 #效率`）。
> 必须**当场抓当日热门话题**，且每个话题都要**贴合本条微头条对应的文章主题 / 账号定位（AI 搞钱 / 提效 / 避坑）**。
> 详见下方「§8.1 微头条话题标签规范」。

**配套写法纪律**：
- 段落极短（1~2 句成段，允许单句成段）；「我说…他说…」推进节奏；金句全篇只留 1~2 句；加粗只用 3~5 处（转折与金句）。
- humanizer 全过：短句、口语化、禁用冒号/破折号/双引号、避免「不是A而是B」排比。
- 文章 1200~2500 字符（观点占 60%，必须留够篇幅把观点写透、煽动情绪激起共鸣）；微头条 200~500 字符。
- **去 AI 味替换（整合自起号课程 · 强制）**：生成时把下列书面/AI 腔词直接替换成口语等价词，禁用原词——「首先/第一点→先说第一点」「其次/第二点→再说第二个」「综上所述→说白了」「值得注意的是→但你发现没」「毋庸置疑→这事没得跑」「因此→所以」「此外→还有一个点」「然而→但是」「从某种程度上说→其实吧」；开头禁用「众所周知/随着…的发展」这类铺垫。
- **标题生成（整合自起号课程 · 强制）**：每篇一口气出 10 个候选标题，分「数字型/反常识型/身份型/悬念型」4 类，挑 TOP3 并附理由；长度 18~25 字；禁用「震惊/绝了/重磅/99%的人不知道」；标题承诺的内容正文必须兑现（禁止标题党）。
- 每篇落盘前按「§8.4 爆款文章自检清单」逐条核，缺项即补。

### §8.2 去 AI 味替换表（整合自起号课程 · 强制）

生成时把下列书面/AI 腔词直接替换成口语等价词，禁用原词：

| 原词（禁） | 替换（用） |
|---|---|
| 首先 / 第一点 | 先说第一点 |
| 其次 / 第二点 | 再说第二个 |
| 综上所述 | 说白了 |
| 值得注意的是 | 但你发现没 |
| 毋庸置疑 | 这事没得跑 |
| 因此 | 所以 |
| 此外 | 还有一个点 |
| 然而 | 但是 |
| 从某种程度上说 | 其实吧 |
| 众所周知 / 随着…的发展 | （直接删掉，别这么开头） |

> 配套 humanizer 五原则照旧全过（短句、口语化、禁用冒号/破折号/双引号、避免「不是A而是B」排比）。

### §8.3 标题生成规范（整合自起号课程）

每篇标题生成时，一口气出 **10 个**候选，分到 4 类，最后挑 TOP3 并附理由：
- **数字型**：带具体数字（如「半年 981 万单」）。
- **反常识型**：打破普遍认知。
- **身份型**：锁定明确人群（如「做自媒体的」「一二线职场人」）。
- **悬念型**：留信息缺口（如「我没敢发出来的那部分，是……」）。
- 长度 **18~25 字**；禁用「震惊 / 绝了 / 重磅 / 99%的人不知道」等夸张词。
- 最终采用标题须与正文强相关、承诺的内容正文要兑现（禁止标题党）。

### §8.4 爆款文章自检清单（整合自起号课程 · 落盘前逐条核）

生成完一篇，按此清单自检，缺项就补：
1. 标题含具体数字；
2. 前 200 字出现「你」字（让读者感到被对话）；
3. 文中至少 1 个对比；
4. 至少 1 个可实操步骤/方法；
5. 有 1 个反常识观点；
6. 结尾有明确互动引导（提问 / 二选一 / 征求意见）；
7. 配图 ≥3 张（文章 3 张方图，已满）；
8. 字数落在 1200~2500（由 check_batch.py 兜底）。

### 范本（用户 2026-09-14 提供 · 本号已验证爆款 · 优先模仿）

**① 文章范本**：《半年981万单AI副业，最赚的偏偏不是写文案》（本号 2026-09-10，展现/阅读很好）

> 昨天闲鱼甩出一份数据，把我看愣了。2026年上半年，平台AI服务订单干了981.6万单，比去年同期涨了157%。买AI服务的人快五百万。
>
> 我身边做副业的人，十个里有八个说自己在用AI写文案、做图、剪视频。你猜订单里涨得最猛的是哪块。说出来你可能不信，是AI编程和建站，同比涨了1732%。
>
> 这个数字挺反常识。大家印象里编程是技术活，普通人碰不了。结果恰恰是这块增长最疯，因为现在用自然语言就能让AI搭个网站、写个小工具。
>
> 还有个细节更颠覆。都说搞AI的是男程序员，数据里女性卖家占62.4%。四线及以下小城市的卖家最多，占32.2%。
>
> 我琢磨了一下，这其实说得通。小城市年轻人时间碎，但审美和需求理解不差。AI把硬核代码门槛削平了，剩下比的就是谁更懂客户要什么。
>
> 真正让我有触动的，是那个13岁女孩。她几乎不懂编程，让AI帮她生成代码，三四天做出个陪读应用，带去活动三天净赚一万八千块。
>
> 你可能会说那是天才小孩，和我无关。但她的打法一点都不天才。把想法说给AI听，让AI出活，自己把控成品质量。
>
> 我自己的体会也是这样。早先我也试过纯靠AI批量出内容接单，累死累活单价还低。后来改成用AI把重复活干掉，腾出手去对接真客户，收入才起来。

**八步结构（照此写）**：
1. **数据开头**：`昨天X甩出一份数据，把我看愣了。` + 硬数字（绝对值 + 同比）
2. **反差钩子**：`我身边…十个里有八个说…你猜涨得最猛的是哪块。说出来你可能不信，是…`
3. **反常识解读**：`这个数字挺反常识。大家印象里…结果恰恰是…`
4. **再甩一个颠覆细节**：`还有个细节更颠覆。都说…数据里…`
5. **我的思考**：`我琢磨了一下，这其实说得通。…`
6. **极端案例**：`真正让我有触动的，是那个13岁女孩。…三天净赚一万八千块。`
7. **回应质疑 + 亲历**：`你可能会说那是天才小孩，和我无关。但她的打法一点都不天才。…我自己的体会也是这样。…`
8. **金句 + 行动建议**：`工具玩得再花哨也没用，关键是…` / `别一上来就囤十几个AI软件。…先接成一单。`

> 半年前我干了件傻事。把每天雷打不动的两小时重复活，全交给了几个AI智能体和一套浏览器自动化脚本。

### §8.1 文章 & 微头条话题标签规范（强制 · 用户 2026-09-14 指定 · 2026-10-13 上调为 4~5 个）

**核心要求**：每篇文章末尾单独一段、每条微头条末尾单独一行，各挂 **4~5 个话题**（2026-10-13 用户指定上调，原 2~3），必须满足三点 ——
1. **当前热门**：来自**当天**抓到的热门话题榜（今日头条热榜 / 抖音热榜 / 科技热点），不是凭空编的。
2. **符合文章定位**：与该篇文章/微头条的主题、以及账号定位（AI 搞钱 / 提效 / 避坑）强相关。
   ❌ 禁止再用写死的常青标签（如固定 `#AI工具 #人工智能 #效率`）。
3. **站内真实存在（可点击）**：话题名必须是**站内话题池原文** —— `scripts/fetch_topics.py` 从发布页话题联想抓到、
   `scripts/merge_topics.py` 合并成 `topics_platform_<日期>.json`。否则发布时走话题选择器搜不到候选 →
   退化成纯文本 → 点不动。**数量不够就扩充池子（多加抓取关键词），不许编话题名。**

**生成器抓取流程（11:00 生成器必须先做这一步）**：
0. 【站内话题池（2026-10-13 恢复，必做）】先跑
   `python scripts/fetch_topics.py --keywords "AI,人工智能,大模型,Token,算力,智能体,副业,职场,自动化,AI编程,AI医疗,AI漫剧,AI长剧,AI剧场,如果不缺钱,超级智能" --top 12 --out topics_probe.json`
   （只跑一次、禁并发，约 2~5 分钟；**失败不阻塞**，退到磁盘上已有的 `hot_topics_today.json` 继续），
   再跑 `python scripts/merge_topics.py` 生成 `topics_platform_<今日日期>.json`（站内真实话题 + 讨论数）。
1. 用 WebSearch 抓当日热门话题（用于**选题参考**与 trending 候选），建议查询：
   - `今日头条热榜 今日`
   - `抖音热榜 今日`
   - `AI 人工智能 热点 今日` / `科技热点 今日`
   - 也可调用「每日热点选题」「hot-topic-content-maker」等热点技能辅助。
2. 从抓取结果中筛出 **6~10 个**同时满足「在榜热门」+「与 AI / 职场 / 副业 / 普通人搞钱提效避坑相关」的话题名。
   ⚠️ WebSearch 热搜词**若要当话题名，必须能在站内话题联想里搜到**（用 `scripts/verify_live_topics.py` 抽查），
   否则只能进选题参考、**不进话题池**。
3. 写 `hot_topics_today.json`（技能根目录）：
   ```json
   {
     "date": "YYYY-MM-DD",
     "trending": ["#AI编程#", "#国产大模型#", "#AI换脸#", "..."],
     "positioning": ["#AI工具#", "#人工智能#", "#副业#", "#职场效率#"],
     "fresh_topics_from_platform": ["#...#", "..."]
   }
   ```
   三个列表条目一律 `#话题名#` 形式、取**站内话题原文**；`trending` 至少 10 条，保证每篇能挑到 4~5 个相关话题。
4. **每篇文章取 4~5 个话题**（末尾单独一段，空格分隔）、**每条微头条取 4~5 个话题**（末尾单独一行）：
   至少 **1 个当日热门**（从 `trending` 里挑最贴合本篇角度的）+ **1 个定位话题**（从 `positioning` 里挑），
   其余按**与该篇正文的相关度**从池里补足到 4~5 个；6 篇之间话题可复用，但每篇挂的必须贴合该篇内容，禁止为凑数挂无关话题。

**格式约定（2026-10-12 二次修正）**：写法统一用 `#话题名#`，但**两个渠道都必须靠发布脚本走话题选择器**才可点击 ——
⚠️ 早期「微头条编辑器会自动识别」的判断**已证伪**（2026-10-12 用户反馈：微头条的话题同样只是文字、点不动）。
- **微头条**：生成器把话题写成正文**末尾单独一行**（空格分隔，写在引流句之后）；
  发布时 `publish_draft.py` 的 `split_trailing_topics()` 把这一行拆出来，再由 `insert_wtt_topics()`
  走编辑器话题选择器（敲 `#` → 点 `.mention-selector-modal .forum-list-item` 候选）插入成真正的话题节点。
- **文章**：生成器把话题写成正文**末尾单独一段**（计入 1200~2500 字数）；
  发布时 `publish_article_draft.py` 的 `split_trailing_topics()` 把这段**拆出来**，
  再由 `insert_article_topics()` 走同一个话题选择器插入成真正的话题节点。
- ⚠️ **两个渠道的话题名都必须取自站内话题池原文**（`topics_platform_<日期>.json` / `hot_topics_today.json`），
  否则选择器搜不到候选、只能退化为纯文本、点不动。无候选时脚本一律**退化为纯文本**（不挂错话题）。

**示例（假设当日热门含「AI编程」「国产大模型」，本篇讲普通人用 AI 建站搞副业）**：
> 半年前我干了件傻事。把每天雷打不动的两小时重复活，全交给了几个 AI 智能体和一套浏览器自动化脚本。
> 上面的只是个开头。完整怎么搭、踩过哪些坑，我写成一篇长文了，去我主页就能翻到。
> #AI编程# #副业# #AI工具# #人工智能# #职场效率#

**兜底**：若 11:00 抓取失败（无网 / 搜索无果 / fetch_topics 报错），退化为「磁盘上已有的 `hot_topics_today.json` + `positioning` 常青池 + 文章主题关键词」，但**必须在当天日更日志里标注「话题未抓热榜，已用兜底」**，次日补抓。⚠️ 兜底也只从池里取，仍**不许编话题名**。

### 图文排版（用户 2026-09-14 指定 · 已与范本核对一致）

**文章 = 文字 + 图片 + 文字 + 图片 + 文字 + 图片**
- 正文分 8~12 个短段；3 张插图由 `compute_image_positions()` **均匀插在段落之间**（不插首尾）。
- 范本《半年981万单AI副业》实测（需滚动触发懒加载）：10 段文字 + 3 张 1024×1024 方图，
  图片落在第 **2 / 5 / 8** 段之后。
- 我们的算法在「10 段 + 3 图」时输出**同样位置**（第 2 / 5 / 8 段后）—— **已核对完全一致，无需改动**。

**微头条 = 文字 + 图片**
- 文字在前，1 张图在后（**复用对应文章首图** `s{N}_a.png`）。范本实测配图 1 张（1536×1024）。

## 9. 高潜选题模板（素材手法，服务于第 8 节）

### 模板 A：数据型反常识 AI 副业
适用：有最新平台报告 / 行业数据 / 官方公告时。
结构：
1. **数据钩子**：用一个大数字开头（如「半年 981 万单」）。
2. **反常识结论**：和大家直觉相反（「最赚的偏偏不是写文案，而是 AI 编程和建站」）。
3. **数据拆解**：涨了多少、哪类人群贡献最大、哪个城市/性别/年龄最猛。
4. **极端案例**：找一个普通人/小孩/小城市年轻人用 AI 赚到钱的真实故事。
5. **务实落点**：工具不重要，能不能用 AI 把一件具体的事跑通、交付出去才重要。
6. **R8 二选一结尾**：你更想试试 AI 编程还是 AI 写文案？/ 你觉得这波机会留给谁？

### 模板 B：亲历式 AI 提效
适用：自己或身边人真实用过某个 AI 工作流。
结构：开头讲具体场景 → 以前多痛苦 → 现在怎么做 → 省了多少时间/赚了多少钱 →  caution 坑点。

### 模板 C：AI 避坑预警
适用：新工具/新平台政策/新骗局出现时。
结构：预警钩子 → 坑点拆解 → 普通人怎么自保 → 立场句。

### 模板 D：第一人称 AI 搞钱亲历（2026-09-14 学习高展现样本 · 推荐）

**样本**：《我用WorkBuddy半小时做了个投标skill，一天挣了3300块》（作者「AI设计老赵」，2026-08-23）。
**为什么高展现**：标题有「具体金额 × 极短耗时」的强反差；正文是完整亲历叙事，细节密、节奏快、有金句、承认翻车。

**标题公式**：`我用[工具]在[极短时间]做了个[具体产物]，[赚了/省了] [具体金额]`
- 必须出现**具体数字**（金额 / 时间 / 数量）；不要「很多」「不少」「大幅」这类虚词。
- 时间与收益要有**反差**（半小时 → 3300 块）。

**正文八步结构**：
1. **堵质疑开头**：读者看到「挣了钱」第一反应是「卖课的吧」。开头先主动排除这类可能。
   例：「先说清楚一件事。这 3300 块不是我卖课挣的，也不是我卖工具挣的。」
2. **起因**：一个**具体的人**（朋友 / 同事 / 客户）+ **一句具体的话**。不要写「很多人都遇到…」。
3. **铺垫**：把对方处境写具体到可信（「二十几个标」「七八十页」「五个子文件夹」）。
4. **动作**：你做的那**一个**关键动作，尽量简单（「我说了一句话」）。
5. **转折（承认不完美）**：第一版出问题，写出来。**这是信任感的来源**，也是 AI 内容最稀缺的真实感。
6. **方法论**：你补的那一步，抽象成一个可复用的小方法（如「先生成 → 再丢回去复核」）。
7. **结果**：具体收益（金额 / 时间 / 数量），不含糊。
8. **金句 + 落点**：一句反常识观点收束（「工具不值钱，值钱的是用工具的经验」），
   再给读者一个「今天就能做」的动作。

**写法纪律**：
- **段落极短**：1–2 句成段，允许单句成段（移动端阅读体验优先）。
- **加粗 3–5 处**：只加在转折句与金句上。
- **对话推进**：用「我说……他说……」带节奏。
- **金句全篇只留 1–2 句**，多了就廉价。
- **第一人称、允许翻车**：不完美比完美真实。

**与模板 A 的区别**：模板 A 是「旁观者 + 数据」，模板 D 是「亲历者 + 故事」。
两者都可产出爆款；**新号 / 冷启动期优先 D**（更容易立住人设、积累信任）。
